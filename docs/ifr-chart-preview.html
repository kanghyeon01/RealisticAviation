1. 글꼴 (VFR 차트 선 글꼴 + 새 글자)

기존 글자(숫자, S F C M D E N O ( ) -)는 그대로이고, A I T / . °를 새로 추가합니다. IAF, IF, FAF, 코스(070°), 거리(2.3), 고도에 씁니다.

2. 기호

3. 예시: 활주로 07 (C 공역, 강하각 5°, STAR 켬)

게임과 같은 축척 계산입니다 (1 px = 20 m). FAF는 1,500 ft에서 강하각이 닿는 곳(5.2 km), IF는 FAF + 3R(4.3 km), IAF는 IF 좌우 3R입니다. 고도는 그 위치에서 절차가 지키는 최저 고도(밑줄)입니다. 착륙에 쓰는 활주로 끝의 절차만 그립니다.
