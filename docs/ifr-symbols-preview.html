IFR 차트 기호 미리보기 (초안 2)

번호별로 보시고 고칠 곳을 말씀해 주세요. 1~8은 지도 오버레이로 게임 세계 위에 선으로 그리는 부분이라, VFR 차트와 같은 선 글꼴을 씁니다. 9~11은 접근 차트를 볼 때 뜨는 작은 창이라 일반 글꼴입니다. 배경의 회색은 정보 보기의 흐린 게임 지도를 대신합니다.

0. 선 글꼴 (A–Z 전체 추가)

웨이포인트 이름과 MAX SPD 같은 글자 때문에 알파벳 전체가 필요합니다. 빨간 글자가 이번에 새로 만드는 글자입니다.

1~8. 지도 오버레이 기호

예시: 활주로 07, 레이어별 (같은 공항을 SID / STAR / 접근으로 나눠 켬)

실제 AIP처럼 활주로 방향마다 SID, STAR, 접근을 따로 봅니다. 축척은 게임 계산과 같습니다 (1 px = 40 m, 강하각 5°, 선회 반경 1.43 km). 웨이포인트 이름은 지어낸 예시입니다 (아래 질문 참고).
글자 배치는 자동입니다: 선·기호·거리 상자를 장애물로 두고, 픽스 이름 → 홀딩 글자 → 방위 → 절차 이름 → 홀딩 방위 → 항로 이름 순으로 후보 자리 중 안 겹치는 첫 자리에 놓습니다. 픽스 이름은 선이 없는 쪽부터 찾습니다. 자리가 없으면 생략하고 그림 아래에 빨갛게 적습니다 (픽스 이름은 생략하지 않음). 홀딩 글자는 홀딩 크기에 맞춰 줄이고, 너무 작아지면 긴 줄부터 뺍니다.

9~11. 접근 차트 창

접근 레이어를 켜면 화면 구석에 뜹니다. AIP 계기접근 차트의 아래쪽 절반(단면도, 표)과 위쪽 정보 칸을 옮긴 것입니다.

INSTRUMENT APPROACH
RNP RWY 07
TWR 118.300
APP 124.675 AERODROME ELEV 59 ft
HEIGHTS RELATED TO THR RWY 07 - ELEV 59 ft
Portland Intl (KPLD)

접근 차트코딩표

10. 단면도 (profile)
* Circling not authorized.
11. 코딩표 (AIP의 "Procedure Coding Tables", 다음 쪽에 따로 싣는 표)

정한 것

1. 웨이포인트 이름: 실제처럼 발음 가능한 영문 5글자 (예: KOVAN, TELIP). 위치로 정해서 다시 불러와도 같고, 도시 안에서 겹치지 않게 합니다.
2. 방위: 진방위 하나만 (게임에 자기 편차가 없음).
3. MSA: 공항 공역 반경 기준 4방위, 지형·장애물로 계산, 접근 차트 창에만.
